Windows 11 installieren

Benötigt:

Windows ISO Datei

Rufus

USB-Stick, mindestens 8GB (alle Daten darauf werden gelöscht!)

Vor Installation alle wichtigen Daten extern absichern

Bootfähigen USB-Stick erstellen

Rufus öffnen

  1. Im Menü "Laufwerk" den USB-Stick auswählen

  2. Unter "Startart" die heruntergeladene Windows 11 ISO Datei auswählen

  3. Rufus konfiguriert automatisch die nötigen Formatierungseinstellungen

  4. "Start"

  5. Der Prozess kann einige Minuten dauern. Sobald der Status "Fertig" angezeigt wird, kann das Programm geschlossen werden

Installation

Alle externen Speicher bis auf den bootfähigen USB-Stick entfernen

PC neustarten, beim Neustart F11 oder F12 (modellabhängig) gedrückt lassen, um ins Bootmenü zu gelangen

  1. "Ein Gerät verwenden"

  2. Bootfähigen USB Stick auswählen

  3. Sprache und Tastatur auswählen → Weiter

  4. "Jetzt installieren"

  5. „Ich habe keinen Product Key“

  6. Die Ziel-Festplatte auswählen (meist „Nicht zugewiesener Speicherplatz“)

  7. „Benutzerdefiniert: nur Windows installieren“ wählen

Nach der Installation mit MAS aktivieren
